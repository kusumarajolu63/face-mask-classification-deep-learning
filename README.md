# Face Mask Classification Using Deep Learning

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify images into two categories: With Mask and Without Mask.

## Technologies
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Gradio
- Google Colab

## Dataset
Face Mask Dataset from Kaggle:
https://www.kaggle.com/datasets/omkargurav/face-mask-dataset

## Features
- Image classification into With Mask and Without Mask.
- Model training and validation.
- Interactive image upload and prediction using Gradio.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Download or load the dataset as instructed in the notebook.
4. Train and evaluate the model.
5. Launch the Gradio interface and upload an image.

## Model Evaluation
Recorded validation accuracy: 90.13%.

Note: Individual predictions may be incorrect. This project classifies the uploaded image; it does not locate faces or draw bounding boxes.
